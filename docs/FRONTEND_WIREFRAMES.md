## Design System

### Color Palette

```
Primary:
┌─────────────────────────────────────────────────────────┐
│  #25D366   WhatsApp Green (Primary Action)              │
│  #128C7E   WhatsApp Teal (Secondary)                    │
│  #075E54   WhatsApp Dark Teal (Headers)                 │
└─────────────────────────────────────────────────────────┘

Status Colors:
┌─────────────────────────────────────────────────────────┐
│  #22C55E   Success/Connected (Green)                    │
│  #F59E0B   Warning/Pending (Amber)                      │
│  #EF4444   Error/Disconnected (Red)                     │
│  #6B7280   Neutral/Offline (Gray)                       │
└─────────────────────────────────────────────────────────┘

Background:
┌─────────────────────────────────────────────────────────┐
│  #0F172A   Dark Background (Slate 900)                  │
│  #1E293B   Card Background (Slate 800)                  │
│  #334155   Border Color (Slate 700)                     │
│  #F8FAFC   Light Text (Slate 50)                        │
└─────────────────────────────────────────────────────────┘
```

### Typography

```
Font Family: Inter, system-ui, sans-serif

Headings:
  H1: 32px / bold    - Page titles
  H2: 24px / semibold - Section headers
  H3: 18px / semibold - Card titles
  H4: 16px / medium   - Subsections

Body:
  Regular: 14px
  Small: 12px
  Code: JetBrains Mono, monospace
```

### Spacing System

```
4px  - xs (tight elements)
8px  - sm (related items)
16px - md (standard gap)
24px - lg (section spacing)
32px - xl (page padding)
```
